# Form Nilai Ujian

Project ini dibuat untuk mengimplementasikan materi struktur kendali dan form processing menggunakan PHP.

## Fitur

Form memiliki input:

- Nama
- Email
- Nilai Ujian

Struktur kendali:

- Jika nilai > 70, maka status **Lulus**
- Jika nilai < 70, maka status **Remedial**

Hasil input ditampilkan kembali pada halaman browser.

## Cara Menjalankan

1. Install XAMPP/Laragon.
2. Letakkan folder project di dalam `htdocs` jika menggunakan XAMPP.
3. Jalankan Apache.
4. Buka browser.
5. Akses:

http://localhost/form-nilai-ujian/
